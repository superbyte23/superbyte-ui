Accordion 01

Build vertically collapsing accordions in combination with our Collapse JavaScript plugin.

First item’s accordion body. It is shown by default, until the collapse plugin adds the classes that control the showing and hiding via CSS transitions.

Second item body. Click the header to expand and collapse the accordion items.

Third item body with a custom card body.
html
              <div class="accordion" id="cdAccordion">
                <div class="accordion-item">
                  <h2 class="accordion-header"><button class="accordion-button" type="button" data-bs-toggle="collapse" data-bs-target="#cdAcc1" aria-expanded="true" aria-controls="cdAcc1">Accordion item #1</button></h2>
                  <div id="cdAcc1" class="accordion-collapse collapse show" data-bs-parent="#cdAccordion"><div class="accordion-body"><strong>First item&rsquo;s accordion body.</strong> It is shown by default, until the collapse plugin adds the classes that control the showing and hiding via CSS transitions.</div></div>
                </div>
                <div class="accordion-item">
                  <h2 class="accordion-header"><button class="accordion-button collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#cdAcc2" aria-expanded="false" aria-controls="cdAcc2">Accordion item #2</button></h2>
                  <div id="cdAcc2" class="accordion-collapse collapse" data-bs-parent="#cdAccordion"><div class="accordion-body">Second item body. Click the header to expand and collapse the accordion items.</div></div>
                </div>
                <div class="accordion-item">
                  <h2 class="accordion-header"><button class="accordion-button collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#cdAcc3" aria-expanded="false" aria-controls="cdAcc3">Accordion item #3</button></h2>
                  <div id="cdAcc3" class="accordion-collapse collapse" data-bs-parent="#cdAccordion"><div class="accordion-body">Third item body with a custom card body.</div></div>
                </div>
              </div>
  • The accordion uses the collapse component internally to make each item collapsible.
  • To render an item expanded by default add .show on the .accordion-collapse element, drop the .collapsed class from the .accordion-button and set aria-expanded="true".
  • Omit the data-bs-parent attribute to keep items open when another is opened, or add .accordion-flush to remove borders and rounded corners.

Provide contextual feedback messages for typical user actions with the handful of available and flexible alert messages.

Primary alert — simple contextual message.
Success alert with icon.
Danger alert with icon.
Warning alert.
Info alert — neutral informational text.
Dark alert — link style.
html
              <div class="d-flex flex-column gap-2">
                <div class="alert alert-primary mb-0">Primary alert &mdash; simple contextual message.</div>
                <div class="alert alert-success mb-0"><i class="hgi-stroke hgi-checkmark-circle-01 me-1"></i> Success alert with icon.</div>
                <div class="alert alert-danger mb-0"><i class="hgi-stroke hgi-cancel-circle me-1"></i> Danger alert with icon.</div>
                <div class="alert alert-warning mb-0">Warning alert.</div>
                <div class="alert alert-info mb-0">Info alert &mdash; neutral informational text.</div>
                <div class="alert alert-dark mb-0">Dark alert &mdash; <a href="#" class="alert-link">link style</a>.<button type="button" class="btn-close float-end" data-bs-dismiss="alert" aria-label="Close"></button></div>
              </div>
  • Alerts are available for any alert text length using the contextual classes .alert-primary, .alert-success, .alert-danger, .alert-warning, .alert-info, .alert-light and .alert-dark.
  • Use the .alert-link class to give any links inside the alert matching colored emphasis.
  • Add a dismiss button with data-bs-dismiss="alert" and the .btn-close class to make the alert dismissible.

Breadcrumb 04

Indicate the current page’s location within a navigational hierarchy that automatically adds separators via CSS.

  1. Home
  2. Components
  3. Docs
  2. Library
  3. Data
html
              <nav aria-label="breadcrumb"><ol class="breadcrumb mb-0">
                <li class="breadcrumb-item"><a href="#">Home</a></li>
                <li class="breadcrumb-item"><a href="#">Components</a></li>
                <li class="breadcrumb-item active" aria-current="page">Docs</li>
              </ol></nav>
              <nav aria-label="breadcrumb" class="mt-3"><ol class="breadcrumb mb-0">
                <li class="breadcrumb-item"><a href="#"><i class="hgi-stroke hgi-house-01"></i></a></li>
                <li class="breadcrumb-item"><a href="#">Library</a></li>
                <li class="breadcrumb-item active" aria-current="page">Data</li>
              </ol></nav>
  • Separators are automatically added in CSS through ::before on .breadcrumb-item.
  • Mark the current page with .active and aria-current="page" on the last item.
  • The default divider is /; change it by overriding --bs-breadcrumb-divider or the $breadcrumb-divider Sass variable.

Button group 06

Group a series of buttons together on a single line or stack them in a vertical column.

html

                  <input type="checkbox" class="btn-check" id="cdBgC1" autocomplete="off"><label class="btn btn-outline-primary" for="cdBgC1">Check 1</label>
                  <input type="checkbox" class="btn-check" id="cdBgC2" autocomplete="off"><label class="btn btn-outline-primary" for="cdBgC2">Check 2</label>
                </div>
                <div class="btn-group" role="group" aria-label="Radio toggle group">
                  <input type="radio" class="btn-check" name="cdBgR" id="cdBgR1" autocomplete="off" checked><label class="btn btn-outline-primary" for="cdBgR1">Radio 1</label>
                  <input type="radio" class="btn-check" name="cdBgR" id="cdBgR2" autocomplete="off"><label class="btn btn-outline-primary" for="cdBgR2">Radio 2</label>
                </div>
                <div class="btn-group btn-group-sm" role="group">
                  <button class="btn btn-ghost">Day</button>
                  <button class="btn btn-ghost">Week</button>
                  <button class="btn btn-ghost active">Month</button>
                </div>
              </div>
  • Wrap buttons in .btn-group to join them into a single control, sized with .btn-group-sm or .btn-group-lg.
  • Combine .btn-check inputs with <label> buttons for checkbox and radio toggle groups.
  • Use .btn-group-vertical to stack buttons vertically, and mix with dropdowns for split-button behavior.

White variant on dark surface:

                <div class="d-flex align-items-center gap-3">
                  <button type="button" class="btn-close" aria-label="Close"></button>
                  <button type="button" class="btn-close" disabled aria-label="Close"></button>

  • To dismiss a component set data-bs-dismiss to the matching value, for example data-bs-dismiss="alert", "modal", "offcanvas" or "toast".
Collapse 10

Toggle the visibility of content across your project with a few classes and our JavaScript plugins.

First collapsible panel — visible by default.
Second collapsible panel.
html
              <div class="d-flex flex-column gap-2">
                <div class="d-flex gap-2">
                  <button class="btn btn-primary btn-sm" type="button" data-bs-toggle="collapse" data-bs-target="#cdCollapse" aria-expanded="false" aria-controls="cdCollapse">Toggle target</button>
                  <button class="btn btn-ghost btn-sm" type="button" data-bs-toggle="collapse" data-bs-target=".cd-multi">Toggle both</button>
                </div>
                <div class="row g-2">
                  <div class="col"><div class="collapse cd-multi show border rounded p-2" id="cdCollapse" style="font-size:12.5px;color:var(--text2)">First collapsible panel &mdash; visible by default.</div></div>

                </div>
              </div>
  • Three classes handle the heavy lifting: .collapse hides the content, .collapse.show shows it and .collapsing is added while the transition runs.
  • Add data-bs-toggle="collapse" and data-bs-target to a trigger element; the target accepts a CSS selector so one trigger can control several panels.
  • For accordion group management add data-bs-parent="#selector" to each collapsible element.
